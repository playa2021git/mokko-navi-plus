対象は index.html。入力は state.work/dims/corners/off/hole/handle/flip/nestX/nestBoard/gap。保存時にJSON化し、読み込み時に検査・復元する。

|画面|寸法の流れ|独立した計算・照合箇所|
|---|---|---|
|3Dの4視点|WORKS.make → parts → rebuild|カメラだけを変更。メッシュの姿勢変換|
|4面|parts → viewShapes/placeView、outer|SVG投影、外寸線の座標変換|
|板一覧・部品表|parts → cutLen、partTable|同寸部品の集計と木目方向|
|寸法を見る・釘位置図|joints → nailSpots → nailCoordinates → drivingFaces|Canvasと説明書SVGの描画、打つ面の反転|
|材料取り・けがき|nest、stockMembers、stockPoint|板面から材料面への座標変換。共通材から複数部品を取る|
|角・穴|state.corners/hole、partOutline、holeOf|3D輪郭、平面図、穴輪郭、STL三角形|
|中に入れる物|parts → compartments → fitsComp/slotsFor|収納物自身の寸法はREF_KINDSとstate.refs|
|単品STL|buildSTL、現在の部品メッシュ|軸変換、接地、縮尺、単精度化|
|一括STL|buildAllSTL → 各作品の初期設計 → buildSTL|作品を並べてから編集状態を復元|

|設計限界|partsForとfitsWith、partsとfitsNow|仮寸法と現在の加工済み形状を別経路で評価|
|相談・選択カード|教材のdims・D、outer(key,true)|教材公称値と完成品の実外寸が二重管理されていた|

座標・移動量は0や負数も正常。正値を要求するのは仕上がり長・幅・厚み等。STLは単精度で許容差が必要。
