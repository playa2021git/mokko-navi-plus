# 公開前の品質監査・修正報告

実施日：2026-10-12。Windows、Chrome・Edgeのheadless実ブラウザ。テスト成功と実物の製作成功は区別する。

## 1. 修正した不具合

- 釘寸法で近い上端・右端からの寸法を選んでいた処理を撤去。縦は地からの絶対寸法、横は指定基準端からの絶対寸法をすべての釘に表示。釘間寸法で基準寸法を代用しない。
- 材料上で反転しても部品座標・指定基準を保ち、けがき図に地の位置を変換表示。番号一覧と製作手引きは同じnailCoordinatesを使用。
- 見た目図・説明書の全画面レイヤーがヘッダーを覆っていた問題を解消。②〜⑤すべてから共通の保存・STL・開くを使用可能。印刷時は操作部を非表示。
- 画面表記を②3Dで確認／3D画面で修正するへ変更。
- 作品変更時に編集を無条件初期化していた問題を修正。保存・破棄・キャンセルを提供。開く前にも変更保護。再読み込み・終了はbeforeunloadで警告。
- 折りたたみ見出しをEnter／Spaceで操作可能にし、展開状態をaria-expandedで表示。
- 収納数を現在○冊／単独最大○冊へ変更し、空のときの寸法比較であることを説明。混在時の残り容量や安定性の保証と区別。
- JSONの手穴位置0を40へ上書きしていた既定値処理を修正。

## 2. 原因

drawDimが釘に近い端を毎回選び、縦列・横列では連鎖寸法を表示していた。番号一覧の左／下からの座標と寸法線が一致していなかった。紙の図面レイヤーはinset:0かつヘッダーより高いz-indexだった。chooseWorkは編集・保存の状態を区別せず初期化していた。見出しはonclickだけだった。

## 4. 全12作品の結果

A〜J・K・Lすべて成功。regression／stl／originals／ends／datumの全テスト成功。1226件の受理寸法で材料取り、板干渉、釘経路、けがき座標を照合。寸法不足・板干渉・角や穴に当たる釘は拒否・警告されることを確認。板厚12mm、切りしろ5mm、支給材150×600を2枚・60×600を1枚、縦びきなしの設計を維持。

Chrome・Edgeとも全12作品の33寸法項目をrange入力で変更。②→③→④→⑤で設計の同一性、けがき・図面・説明書の有限値と印刷範囲、4縮尺STLの寸法・Z=0を検証。K/Lの加工輪郭と体積、A〜Lの角・穴・参照物の除外を別のSTL回帰で確認。

## 5. 基準面の結果

2065釘について、初期寸法、寸法変更、材料位置、反転、角加工、穴加工を照合。下・中央・上に近い釘、左右に偏った釘を含む。地寸法はtoFaceのyと一致し、始点はY(0)。横寸法は指定端との差、始点はX(datum.x)。fromBottom／fromLeftが存在しないことを自動確認。

Lの211mm脚板では地30・166・196mmを表示。上45・15mmへの置換をしない。釘番号と一覧は同じレコード、3Dとけがきは同じnailSpots位置から生成。素材上の点・地印はstockPointで反転を変換。製材端が接地・接合に利用されない向きを手動指定した場合、既存の端面警告を維持する。部品の地は動かさず、必要な端の直角仕上げ・組立方向を授業で確認する。

修正前後スクリーンショット：成果物のnail-datum-before.png、nail-datum-after.png。前は天45・15、後は地166・196。

## 6. 保存・STL・開く

Chrome・Edge×1280×720／1366×768／1920×1080×②③④⑤＝24組成功。全組で保存JSONを実ダウンロードし寸法・角・穴を確認。STLを実ダウンロードし名前と5分の1を確認。工程別にバイナリSHA-256が一致。各工程の開くボタンからファイル選択・復元を実施。ボタン位置が画面内でクリックを遮られていないこと、印刷時の非表示を確認。各画面の画像を取得。

両ブラウザで未編集は警告不要、キャンセルは変更保持、保存後の作品変更は元JSONを保存、保存せず変更は明示破棄、再読込は保存値を復元して未変更扱い。beforeunloadイベントと実際のreload警告ダイアログのキャンセルで元設計が維持されることを確認。混在収納・キーボード折りたたみを確認。ページ例外なし。

## 7. 残る問題・未検証

- ネイティブSTL保存ダイアログshowSaveFilePickerの実操作は未検証。ダウンロード方式は実検証。
- ダウンロード開始後に利用者が保存を取り消したか、ブラウザが保存を遮断したかをアプリ側では確実に判断できない。保存扱いは開始時点。保存ファイルの存在を確認する。
- beforeunloadはブラウザの制限、強制終了、モバイル終了等で警告されない場合がある。無条件の保護は保証しない。
- 教材実物、学校端末、学校ネットワーク、生徒による授業での操作は未検証。スクリーンショットによる確認は実ブラウザ自動検証を補うもので、全利用環境の保証ではない。
- 異なる収納物の単独最大は合算できない。外にはみ出す本の安定性、実際の取り出しやすさは別途確認。
