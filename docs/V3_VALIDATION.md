# V3検証記録

2026-10-12。Windows / Chromeで実施。

- 材料端：A〜Lの材料境界・5mm切りしろ・両端配置・初期方向を確認。添付画像のように露出した上端、単に面がそろった端、浮いた端を合格にしない。
- 製作：1226件の受理寸法で、材料不足・板の干渉・釘の進路・けがき座標を検証。角・穴を加工した際の不適切な釘も検出。
- ブラウザ：A〜Lの全33寸法項目を実際のrange inputで変更。けがき・見た目図・説明書への同じ形状の反映、印刷範囲、4縮尺のSTL実寸・有限座標・Z=0を確認。変更寸法の説明文のはみ出しを修正。
- K/L：JSON保存・読込で寸法と角加工を復元。4縮尺のファイル名、実ダウンロード、2ページ説明書PDF、1366×768表示、ページ例外なしを確認。
- STL：A〜L全4縮尺、K/L実体積、角・穴の反映、参照物を含まないことを確認。

単体：node tests/regression.cjs / tests/stl.cjs / tests/originals.cjs / tests/ends.cjs。
ブラウザ：PlaywrightとChromeを用意し node tests/browser-audit.cjs。PLAYWRIGHT_MODULEでモジュール位置、AUDIT_OUTPUTで出力先を指定可能。

検証はソフトウェアの寸法・加工・表示の整合性。実物の耐荷重試験は未実施。Lの80kg対応は保証しない。ブラウザのネイティブ保存ダイアログは未検証、ダウンロード経路を実検証。
