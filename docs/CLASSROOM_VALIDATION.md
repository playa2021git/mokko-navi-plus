## 寸法変更と出力

`tests/learning-consistency.cjs`：全12作品、各寸法操作の下限・上限・中間を含む99条件が成功。

- 変更後のモデルの部品寸法と、説明書の部品表に実際に表示された寸法を照合。
- 説明書・見た目図の外寸、各板の釘位置図の幅・高さ・釘数を照合。
- けがきで全ての部品が現在の材料に対応していることを確認。Gの共通取っ手2個、Kの共通側板も対象。
- STLのバイナリ頂点から外寸を求め、現在のモデルの外寸と4縮尺（1/2・1/3・1/5・1/10）で照合。
- 全12作品で幅・高さを組み合わせて変更し、実際にダウンロードしたJSONを開き直して、形状と説明書の内容が一致することを確認。
- 説明書を開いたまま寸法が変更された場合、および印刷直前に寸法が変更された場合の再生成を確認。
- 不正な部品の重なりが生じた場合、古い説明書を残さずエラーを表示し、印刷直前にも古い図が復活しないことを確認。

`tests/browser-audit.cjs`：全12作品・33通りの寸法変更が成功。釘の進路、材料不足、工程移動による形状保持、SVG文字の用紙外へのはみ出し、説明書右列の幅、4縮尺のSTLを確認。

## ブラウザテストの再実行

PlaywrightとChromeを用意し、リポジトリのディレクトリから以下を実行する。

```sh
node tests/browser-audit.cjs
node tests/material-editing.cjs
node tests/learning-consistency.cjs
node tests/ends-display.cjs
```

今回のクラウドではシステムChromiumと同梱Playwrightを使用し、リポジトリ外の`PLAYWRIGHT_MODULE`アダプターでブラウザを指定した。
クラウドのファイルURL制限に対応するため、PythonのローカルHTTP配信へURLを変換して実行した。
実行結果はChromiumでの結果であり、Chrome・Edgeそれぞれの製品ブラウザや、授業で使うChromebook実機での結果とは区別する。

対象の99条件と既存の回帰検証の記録であり、任意の寸法・部品移動・加工の全組み合わせを網羅したという意味ではない。
